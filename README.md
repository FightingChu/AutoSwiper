# AutoSwiper — 安卓通用自动上滑小工具

基于 Android 无障碍服务（AccessibilityService）的通用自动上滑工具：在**任意 App 页面**每 1 秒模拟一次上滑手势，触点随机，带常驻悬浮窗一键开关。

> ⚠️ 合规提醒：部分 App 的用户协议禁止自动化操作，请仅用于技术研究与个人自动化，风险自负。

## 功能

| 功能 | 说明 |
|------|------|
| 自动上滑 | `dispatchGesture()` 模拟真实上滑手势，任意 App 通用 |
| 固定节拍 | 1 秒滑动 1 次 |
| 触点随机 | 每次起点 X/Y、终点 X/Y、轨迹弧度、手势时长均随机，不固定一个点 |
| 次数/时长设置 | App 内可设按次数或按时长（秒）；1 秒 1 次，两者等价；0 = 无限 |
| 悬浮窗 | 由 App 内「显示/隐藏悬浮窗」按钮控制（开启无障碍**不**自动弹窗）；可拖动、一键开始/停止，实时显示剩余次数 / 反弹状态 |
| 自动停止 | 设定次数滑完自动停止，**悬浮窗保留**，可随时再次开始 |
| 到底反弹（v1.1） | 主方向向下滑（看下面）；检测到页面到底（连续 2 次内容无变化）自动反向向上滑**可设置次数**，再回到原方向循环。反弹次数 = 0 时关闭该特性 |
| 悬浮窗可控显隐 + 自动收缩（v1.2） | 开启无障碍不再自动弹窗，改为 App 内按钮显隐；悬浮窗贴边静止 3 秒自动收缩为小圆点，点圆点再展开 |

## v1.1 新增：到底反弹

- 主滑动方向：向下滑（看下面，原 v1.0 行为）。
- 到底检测：每 tick 采样页面文本指纹，连续 2 次无变化判定「到底」。
- 触发反弹：自动切换为反向「向上滑」（看上面），滑动次数 = App 内「到底反弹设置」的值（默认 10，0 = 不反弹）。
- 反弹结束后回到主方向继续，**如此来回循环自动刷**，直到总次数/时长到或手动停止。
- 悬浮窗在反弹时显示「反弹中（向上滑）剩余 N 次」。

## v1.2 新增：悬浮窗可控显隐 + 自动收缩

- **显隐由按钮控制**：开启无障碍服务后**不再自动弹出**悬浮窗。回到 App，点「显示悬浮窗」才调出；不用时点「隐藏悬浮窗」收起。实现上 App 通过广播 `SHOW_FLOAT` / `HIDE_FLOAT` 通知服务。
- **自动收缩**：悬浮窗贴边（距任一屏幕边缘 < 24dp）且**静止超过 3 秒**时，自动收缩为小圆点；点击圆点立即展开回完整面板。拖动或点击按钮会重置静止计时。
- 默认展开位置设在屏幕中上方（x=80dp, y=160dp），既不会一弹出来就触发贴边收缩。

## 使用步骤

1. 安装 `AutoSwiper.apk`
2. 打开 App，设置滑动次数或时长，点「保存设置」
3. 点「去开启无障碍服务」，找到 **AutoSwiper** 并开启
4. 返回 App，点「显示悬浮窗」调出悬浮窗 → 切到任意 App → 点悬浮窗「开始」
5. 次数到自动停止（悬浮窗不消失）；也可随时点「停止」
6. 不用时回 App 点「隐藏悬浮窗」收起

## 技术要点

- 悬浮窗使用 `TYPE_ACCESSIBILITY_OVERLAY`（API 27+），**无需** `SYSTEM_ALERT_WINDOW` 权限，绕开国产 ROM 悬浮窗限制
- 手势随机化范围：起点 X ∈ [30%, 70%] 屏宽，起点 Y ∈ [65%, 82%] 屏高，终点 Y ∈ [18%, 35%]，时长 250~450ms，轨迹带随机弧度
- minSdk 24（`dispatchGesture` 要求 API 24+），targetSdk 33，compileSdk 34

## 构建

```bash
# 需要 JDK 17 + Android SDK (platform 34)
gradle assembleDebug
# 产物：app/build/outputs/apk/debug/AutoSwiper.apk
```
